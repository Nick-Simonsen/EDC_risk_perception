Public Risk Judgments of Endocrine-Disrupting Chemicals: Psychometric Structure, Exposure Pathways, and Cross-National Differences
=======
This repo contains the manuscript TeX files, processed data, processing scripts, and data analysis scripts for reproducing the results in Simonsen et al. (2026): Public Risk Judgments of Endocrine-Disrupting Chemicals: Psychometric Structure, Exposure Pathways, and Cross-National Differences

How to cite: Simonsen, N., Pravednikov, A., Lagerkvist, C.-J., & Perkovic, S. (2026). Public risk judgments of endocrine-disrupting chemicals: Psychometric structure, exposure pathways, and cross-national differences. *Risk Analysis*, *46*, e70381. https://doi.org/10.1111/risa.70381


## Requirements To Reproduce Results

### R (version 4.3.1)
Install required packages for statistical analyses, tables, and figures in LaTeX format:
````bash
Rscript install_packages.R
````

### Python (version 3.12.0)
Required packages for pre-processing raw data (raw data not available due to privacy reasons)
````bash
pip install -r requirements.txt
````
